Privacy policy

Last updated: 31 October 2026

Shorts Uploader is a private tool used only by its owner to manage the owner's own YouTube channel. It has no other users.

What it accesses

With the owner's permission, through Google's OAuth sign-in, it uses the YouTube Data API and YouTube Analytics API to:

  • upload videos to the owner's channel and set their title, description, tags and publish time;
  • read public information about trending YouTube videos;
  • read performance statistics for the owner's own videos.

Where data is kept

The sign-in token and statistics are stored only on the owner's own computer. Nothing is sold, shared with third parties, or used for advertising. The tool collects no data about anyone else.

Google and YouTube

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be sent to the owner through the contact options on the owner's YouTube channel.
